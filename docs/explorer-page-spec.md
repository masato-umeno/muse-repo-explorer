# Explorer page spec

A phone-first source-code viewer used as a Muse space (web artifact).

**The page is bundled: [`page/index.html`](../page/index.html).** Nobody needs to build it from
this spec; `repo_explorer.py refresh` produces upload-ready files. This document describes the
data format and the behavior, for people who want to change or port the page.

## Delivery

`refresh` writes three files to `~/workspace/repo-explorer/dist/`:

| Form | Files | Refresh replaces |
| --- | --- | --- |
| two-file (preferred) | `index.html` + `snapshot.json` | `snapshot.json` only |
| single-file | `explorer.html` (data embedded) | `explorer.html` |

The page first looks for data embedded in `<script id="snapshot-data" type="application/json">`;
if that tag is empty, it fetches `snapshot.json` from the same folder. The embedded JSON has
every `<` escaped as `\u003c`, so file contents can never close the script element.

## Snapshot format

```json
{
  "generated_at": "2026-11-22T10:24:53+09:00",
  "repos": [
    {
      "id": "your-org/your-repo",
      "branch": "main",
      "head": "abc1234",
      "committed_at": "2026-11-21T18:02:11+09:00",
      "files": [
        {"path": "src/main.ts", "size": 1234, "content": "file text (UTF-8)"},
        {"path": "assets/logo.png", "size": 5678, "skipped": "binary"},
        {"path": "data/huge.json", "size": 999999, "skipped": "large"},
        {"path": ".env", "size": 120, "skipped": "excluded"},
        {"path": "docs/latest", "size": 10, "skipped": "symlink"},
        {"path": "vendor/lib", "size": 0, "skipped": "submodule"}
      ]
    }
  ]
}
```

- Only text files have `content`. Everything else has `skipped`:
  `binary`, `large` (over 300 KB), `excluded` (by `exclude.txt`), `symlink`, `submodule`.
- Content is taken from the `head` commit.
- Generated by `tools/update_snapshot.py`.

## Behavior

- Phone-first layout. Dark and light themes.
- **Languages: English, 日本語, 简体中文, 한국어.** Pick from the browser language
  (`navigator.language`), fall back to English, and offer a switcher. Keep all UI strings in one
  dictionary so a language can be added in one place.
- Repository switcher, grouped by owner. Show `branch`, `head` and `committed_at` per repository.
- Folder tree with expand/collapse. Tap a file to show it.
- Code view: monospace, line numbers, horizontal scroll, light syntax highlighting (by file
  extension is enough), copy button.
- Cross-repository file search: substring match on all paths; tapping a result switches to that
  repository and opens the file.
- `skipped` files appear in the tree; opening one shows a localized message for the reason
  (binary / too large / hidden by exclude list / symbolic link / submodule).
- Show `generated_at` on screen.
- URL hash `#<repo>:<path>` so the phone's back button returns from a file to the tree.
- Remember the chosen language and repository (localStorage, failures ignored).
- Render only the tree at first; render file content when tapped (the data is large).
- Keep `snapshot.json` as a single asset separate from the page code, so refreshing is a
  replacement of that asset only.

## Security

- All file content is HTML-escaped before highlighting; nothing from the snapshot is ever
  inserted as markup.
- No external requests (no CDN, fonts or analytics). `noindex` and `no-referrer` are set.

- The snapshot contains the full source of private repositories.
  **Never share this page publicly** (no public link). It is meant as a private space for you.
