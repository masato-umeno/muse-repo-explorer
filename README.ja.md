# muse-repo-explorer

[English](README.md) | **日本語** | [简体中文](README.zh-CN.md) | [한국어](README.ko.md)

muse-repo-explorer は、GitHub リポジトリのローカル clone を Muse の環境に保持し、次の2つの用途に提供します。

- **Muse 向け：** ソースコードをローカルのファイルから読み込みます。コネクタ経由より高速で、トークン消費も大幅に抑えられます。
- **利用者向け：** clone のスナップショットから、スマートフォンでの閲覧に適した非公開のコードブラウザ（Muse のスペース）を作成します。ファイル名とファイルの内容を検索でき、Markdown は整形して表示し、Mermaid の図も描画します。ページは利用者の言語（英語・日本語・中国語・韓国語）で構築されます。各リポジトリの内容は必要になった時点で読み込むため、リポジトリが増えても表示は遅くなりません。

## セットアップ

次のプロンプトを Muse に送信してください。セットアップ中に求められる操作は、GitHub へのサインインの承認と、対象リポジトリの選択の2点です。リポジトリは少なくとも1つ必要で、このリポジトリをサンプルとして使うこともできます。プロンプトは何度でも再送信でき、完了済みの手順は省略されます。

````text
「muse-repo-explorer」を私の環境に構築してください。作業中は常に次のルールを守ってください。
- トークン節約：下に書いたコマンドだけを実行し、その短い出力だけを読むこと。dist/ 以下のファイルと snapshot.json は開かず、表示も貼り付けもせず、ファイルパスのままアップロードすること。独自のスクリプトを書いたりページを自作したりしないこと（ページは完成品があります）。
- プライバシー：スペースは非公開のままにし、公開リンクは作らないこと。パスワードやトークンを私に求めないこと。clone するのは私が選んだリポジトリだけにすること。

以下の手順で C は次のコマンドを指します：python3 ~/workspace/muse-repo-explorer/tools/repo_explorer.py

1. ツールの取得。~/workspace/muse-repo-explorer があれば `git -C ~/workspace/muse-repo-explorer pull --ff-only`、なければ `git clone https://github.com/masato-umeno/muse-repo-explorer ~/workspace/muse-repo-explorer` を実行する。続けて `C setup --lang LANG` を実行する。LANG は私がこの会話で使っている言語（en、ja、zh-CN、ko のいずれか）にする。それ以外の言語の場合は --lang を付けずに `C setup` を実行する。
2. サインイン（setup が "signed in" と表示したら省略）。`C login` を実行し、表示された URL とコードをそのまま私に見せる。続けて `C login --wait` を実行する（私が承認すると終わる）。
3. リポジトリの選択。リポジトリは少なくとも1つ必要。`C list` を実行して結果を私に見せ、どれを含めるか聞く（「プライベートのもの全部」のように答えることがあります）。私の選んだものを `C clone owner/repo ...` で取得する。選べるリポジトリがない場合や私が何も選ばなかった場合は、このツール自身のリポジトリをサンプルとして含めるか私に確認し、同意したら `C clone masato-umeno/muse-repo-explorer` を実行する。clone の出力でリポジトリの合計が1以上になるまで次へ進まないこと。
4. ビルド。`C refresh` を実行する。
5. スペースの作成。refresh が表示したフォルダ内のファイルをすべて、data/ サブフォルダの構成を保ったまま手を加えずにアップロードし、非公開の Muse スペース「リポジトリエクスプローラー」を作る。スペースが HTML 1ファイルしか持てない場合は、代わりに explorer.html をアップロードする。その後 `C mark-synced --mode folder`（1ファイルの場合は `--mode single-file`）を実行する。
6. 3行以内で報告：GitHub アカウント、リポジトリ数、作成したスペース。

今後のために覚えておいてください：私が「エクスプローラーを最新化して」と言ったとき、または既存の定期ジョブの最後に、`C refresh` を実行する。UP_TO_DATE と出たらそこで終了。PAGE_UPDATE_NEEDED と出たら、列挙されたファイルだけをアップロードし、削除対象として列挙されたファイルを削除してから、`C mark-synced` を実行する。
````

## 使い方

- **ページの更新：** Muse に「エクスプローラーを最新化して」と依頼します。スペースが更新されるのは新しいコミットがあった場合だけで、アップロードされるのは該当リポジトリのファイルのみです。
- **リポジトリの追加：** Muse に clone を依頼したうえで、最新化します。
- **ファイルの非表示：** `~/workspace/repo-explorer/exclude.txt` に glob パターン（例：`.env*`、`*.pem`）を記述します。詳しくは[運用](docs/operations.md)を参照してください。

## セキュリティ

スナップショットには、対象リポジトリのソースコードがすべて含まれます。エクスプローラーページは非公開のまま運用し、`snapshot.json` をコミットしたり共有したりしないでください。サインインはデバイスフローでのみ行ってください。詳細は[セキュリティ](docs/security.md)を参照してください。
